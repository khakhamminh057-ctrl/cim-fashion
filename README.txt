CIM FASHION - WEBSITE BÁN QUẦN ÁO
====================================

Cách chạy:
1. Giải nén file ZIP.
2. Mở index.html bằng Chrome/Edge để xem website.
3. Website không cần cài server để chạy các chức năng giao diện, tìm kiếm, chi tiết sản phẩm, giỏ hàng và form đặt hàng demo.

Các trang:
- index.html: trang chủ + 18 sản phẩm
- product.html?id=PL-NAM-001: trang chi tiết sản phẩm
- cart.html: giỏ hàng
- checkout.html: đặt hàng

Lưu ý:
- Ảnh sản phẩm đang dùng ảnh từ Unsplash qua Internet nên khi mở website cần có mạng để tải ảnh.
- Đơn hàng hiện là DEMO phía trình duyệt: chưa gửi dữ liệu thật tới shop và chưa kết nối cổng thanh toán.
- Để mọi người truy cập bằng một đường link công khai, tải toàn bộ thư mục này lên một dịch vụ hosting tĩnh như GitHub Pages, Netlify hoặc Cloudflare Pages.
